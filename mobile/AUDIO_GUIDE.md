# 🎵 دليل إضافة الأصوات للعبة

## الملفات الصوتية المطلوبة

ضع الملفات التالية في المجلد: `android/app/src/main/res/raw/`

### 1. **game_music.mp3** (موسيقى خلفية)
- موسيقى خفيفة ومرحة للأطفال
- مدة: 30-60 ثانية (loop)
- حجم: أقل من 500KB

**مصادر مجانية:**
- https://freesound.org/
- https://www.zapsplat.com/
- https://mixkit.co/free-sound-effects/game/

### 2. **success.mp3** (صوت النجاح)
- صوت "ding" أو "chime" قصير
- مدة: 0.5-1 ثانية
- مثال: نغمة جرس لطيفة

### 3. **error.mp3** (صوت الخطأ)
- صوت "buzz" أو "wrong" لطيف
- مدة: 0.5-1 ثانية
- مثال: نغمة منخفضة قصيرة

### 4. **combo.mp3** (صوت الـ Combo)
- صوت متصاعد ومثير
- مدة: 0.5-1 ثانية
- مثال: نغمة صاعدة سريعة

### 5. **victory.mp3** (صوت الفوز)
- صوت احتفالي
- مدة: 2-3 ثوانٍ
- مثال: fanfare قصير

### 6. **warning.mp3** (صوت التحذير)
- صوت تنبيه لطيف
- مدة: 0.5 ثانية
- مثال: beep قصير

## كيفية إضافة الأصوات

### الخطوة 1: تحميل الأصوات
قم بتحميل الملفات من المصادر المجانية أعلاه

### الخطوة 2: تحويل الصيغة (إذا لزم الأمر)
- تأكد أن الملفات بصيغة MP3
- يمكن استخدام https://online-audio-converter.com/

### الخطوة 3: نسخ الملفات
```bash
# انسخ الملفات إلى:
mobile/android/app/src/main/res/raw/

# يجب أن تكون أسماء الملفات بأحرف صغيرة فقط
# بدون مسافات أو رموز خاصة
```

### الخطوة 4: إعادة البناء
```bash
cd mobile
npm run android
```

## ملاحظات مهمة

1. **أسماء الملفات**: يجب أن تكون بأحرف صغيرة فقط (lowercase)
2. **الصيغة**: MP3 هي الأفضل للتوافق
3. **الحجم**: حاول أن تكون الملفات صغيرة (أقل من 500KB لكل ملف)
4. **الترخيص**: تأكد من استخدام أصوات مجانية أو مرخصة
