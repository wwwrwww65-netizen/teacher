# شرح آلية عمل الدروس في التطبيق 📚

## 🔄 سير العمل الكامل:

### 1️⃣ **اختيار المادة** (CurriculumScreen)
- المستخدم يختار مادة من الصفحة الرئيسية (مثل: اللغة العربية 📖)
- يتم الانتقال إلى صفحة `SubjectLessonsScreen`

### 2️⃣ **صفحة دروس المادة** (SubjectLessonsScreen)
عند الدخول لهذه الصفحة:

#### أ) **تحميل الدروس**:
```javascript
const loadLessons = async () => {
    const storedLessons = await AsyncStorage.getItem(`lessons_${subject.id}`);
    // يتم تحميل الدروس المحفوظة من AsyncStorage
}
```
- يتم تحميل الدروس المحفوظة محلياً لهذه المادة
- إذا لم توجد دروس، تظهر رسالة "لا توجد دروس بعد"

#### ب) **إنشاء درس جديد**:
عند الضغط على زر "إنشاء درس جديد":
1. يظهر Modal (نافذة منبثقة)
2. المستخدم يدخل:
   - **عنوان الدرس** (إجباري)
   - **وصف الدرس** (اختياري)
3. عند الضغط على "إنشاء":
```javascript
const newLesson = {
    id: Date.now().toString(),
    title: newLessonTitle.trim(),
    description: newLessonDescription.trim() || 'درس جديد',
    createdAt: new Date().toISOString(),
    completed: false
};
```
4. يتم حفظ الدرس في AsyncStorage
5. يظهر في قائمة الدروس

### 3️⃣ **الدخول للدرس** (عند النقر على درس)
عند النقر على أي درس، يحدث التالي:

```javascript
const handleLessonPress = (lesson) => {
    navigation.navigate('Classroom', {
        mode: 'lesson',
        initialMessage: `مرحباً! سنبدأ الآن درس "${lesson.title}". ${subject.initialMessage}`,
        targetItem: subject.targetItem,
        subject: subject.id,
        lessonId: lesson.id
    });
};
```

#### ما يحدث:
1. **الانتقال إلى ClassroomScreen** (الفصل الدراسي)
2. **إرسال البيانات التالية**:
   - `mode: 'lesson'` - وضع الدرس
   - `initialMessage` - رسالة ترحيبية مخصصة تحتوي على:
     - اسم الدرس
     - رسالة المادة الأصلية
   - `targetItem` - العنصر المستهدف (مثل: حرف 'أ' للعربية)
   - `subject` - معرف المادة
   - `lessonId` - معرف الدرس

3. **في ClassroomScreen**:
   - يتم تشغيل المعلمة نورا (AI)
   - تبدأ المعلمة بالرسالة الترحيبية
   - يتم فتح جلسة Gemini Live
   - تبدأ المحادثة التفاعلية مع الطالب

### 4️⃣ **مثال عملي**:

#### إذا أنشأت درس "الحروف الأبجدية" في مادة اللغة العربية:

1. **عند النقر على الدرس**:
```
الانتقال → ClassroomScreen
```

2. **الرسالة الترحيبية**:
```
"مرحباً! سنبدأ الآن درس "الحروف الأبجدية". 
أهلاً بك يا بطل! اليوم سنتعلم الحروف العربية الجميلة. دعنا نبدأ بحرف الألف."
```

3. **ما يحدث في الفصل**:
   - 🎤 المعلمة نورا تتحدث معك
   - 📝 يمكنك الكتابة على السبورة
   - 🎯 يمكن أن تظهر اختبارات
   - 🗣️ يمكنك التحدث والتفاعل

### 5️⃣ **إدارة الدروس**:

#### **حذف درس**:
- زر الحذف 🗑️ بجانب كل درس
- تأكيد قبل الحذف
- يتم الحذف من AsyncStorage

#### **تخزين الدروس**:
```javascript
AsyncStorage.setItem(`lessons_${subject.id}`, JSON.stringify(lessons))
```
- كل مادة لها دروسها الخاصة
- التخزين محلي (لا يحتاج إنترنت)
- البيانات تبقى حتى بعد إغلاق التطبيق

## 📊 ملخص البيانات المحفوظة لكل درس:

```javascript
{
    id: "1737490123456",           // معرف فريد
    title: "الحروف الأبجدية",      // العنوان
    description: "تعلم الحروف",    // الوصف
    createdAt: "2026-01-21T...",   // تاريخ الإنشاء
    completed: false                // حالة الإكمال
}
```

## 🎯 الخلاصة:

**المسار الكامل**:
```
اختيار مادة → عرض دروس المادة → إنشاء/اختيار درس → الدخول للفصل → التعلم مع المعلمة نورا
```

**الميزات**:

- ✅ حفظ الدروس محلياً
- ✅ حذف الدروس
- ✅ رسائل ترحيبية مخصصة
- ✅ تكامل كامل مع ClassroomScreen
