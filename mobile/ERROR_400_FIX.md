- الميزة متوفرة فقط في `gemini-1.5-pro`


```javascript

    google_search_retrieval: {
        dynamic_retrieval_config: {
            mode: "MODE_DYNAMIC"
        }
    }
}]

// السبب: يسبب خطأ 400 حالياً
```

### 3️⃣ **الاعتماد على معرفة Gemini:**
- Gemini 1.5 Pro لديه معرفة واسعة بالمناهج الدراسية
- تم تحسين الاستعلام ليكون أكثر وضوحاً
- النتائج ستكون دقيقة بناءً على معرفة النموذج
