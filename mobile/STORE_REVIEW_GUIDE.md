# 🚀 دليل رفع التطبيق لمتجر جوجل بلاي (Google Play Store Review Guide)

لضمان قبول التطبيق دون مشاكل تتعلق بنظام الاشتراكات غير المكتمل، تم تفعيل **"وضع المراجعة" (Store Review Mode)**.

## 🛠️ ماذا يفعل "وضع المراجعة" حالياً؟
1.  **فتح المميزات تلقائياً:** يعتبر جميع المستخدمين مشتركين (Premium) تلقائياً.
2.  **إخفاء واجهات الشراء:** تم إخفاء زر "👑 PRO" من الشاشة الرئيسية لمنع المراجعين من محاولة إجراء عمليات شراء وهمية.
3.  **تجاوز جدران الدفع:** لن تظهر أي نافذة تطلب الاشتراك.

---

## 🔄 كيفية إلغاء هذا الوضع (بعد قبول التطبيق)

عندما يتم قبول التطبيق وتريد تفعيل نظام الاشتراكات الحقيقي، اتبع الخطوات التالية:

### 1. في ملف `src/services/SubscriptionService.js`
قم بتغيير القيم التالية في الـ `constructor`:

```javascript
// البحث عن هذه الأسطر:
this.isSubscribed = true; // اجعلها false
this.subscriptionType = 'yearly'; // اجعلها null
this.expiryDate = new Date(2030, 0, 1); // اجعلها null
this.STORE_REVIEW_MODE = true; // اجعلها false
```

### 2. في ملف `src/screens/HomeScreen.js`
ستجد شرطاً حول أيقونة التاج (👑 PRO)، سيعود للعمل تلقائياً بمجرد إرجاع `STORE_REVIEW_MODE` إلى `false`.

---

## 📝 نصيحة عند الرفع
في قسم **"App Access"** داخل Google Play Console، قم بتزويد المراجعين بحساب تجريبي (إيميل وباسورد) واكتب لهم في الملاحظات:
> "This account provides full access to all premium features for review purposes."

هذا سيجعل المراجع يرى التطبيق مكتملاً ومميزاً دون الحاجة للمرور ببوابة الدفع.
